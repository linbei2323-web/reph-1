## 第 1 阶段:学习会计基础

**【你的记录】** 总账会计、应收和应付、应计、银行对账、毛到净收入。

| 概念 | 在本项目里的意思 | 后面用在 |
|---|---|---|
| 总账(GL) | 每笔交易都记成借贷相等的分录,记入各个科目 | 试算平衡检查(第 5 阶段) |
| 应收 / 应付(AR / AP) | 客户欠你的 / 你欠供应商的。每个都有明细账(发票明细),明细账合计必须等于总账控制科目 | 明细账与总账核对(第 5 阶段) |
| 应计(Accruals) | 在现金流动之前先记的费用或扣减。制药行业里最大的是返利 | 毛到净核对(第 6 阶段) |
| 银行对账 | 每条银行流水都要对上账里的一笔付款,对不上的就是异常 | 银行匹配(第 5 阶段) |
| 毛到净(GTN) | 销售总额 − 返利 − 价格补差 − 退货 − 现金折扣 = 净收入 | 毛到净桥接图(第 6 阶段) |

**要做:** 读 ERPNext 会计分录文档,以及药企年报中关于收入 / 毛到净的部分(参考:BMS 2025 10-K)。用自己的话写一页术语表,放在 `docs/glossary.md`。

**参考:** 会计指南 [Accounting for the Pharma FP&A Project](https://claude.ai/artifact/WGRPZcS178yJYTPWv8m85o)(含练习和中英文术语表)。

## 第 3 阶段:在 ERPNext 记 12 个月的账

**【你的记录】** 采购、销售、收款、供应商付款、返利计提和结算;相互关联的发票、付款、费用、调整和银行记录,覆盖 12 个月。结果:12 个月、4 个成本中心共 4,800 笔交易。

| 业务事件 | ERPNext 单据 | 说明 |
|---|---|---|
| 卖给客户 | 销售发票(Sales Invoice) | 标注产品和成本中心 |
| 从供应商采购 | 采购发票(Purchase Invoice) | 标注成本中心 |
| 客户收款 / 供应商付款 | 付款单(Payment Entry) | 关联到对应发票 |
| 返利计提与结算、调整 | 日记账凭证(Journal Entry) | 每月计提,之后结算 |
| 银行流水 | 银行交易(Bank Transaction) | 银行匹配的数据来源 |

- 每张单据都会在 ERPNext 的 **GL Entry** 表里写入行(日期、科目、借方、贷方、成本中心、往来单位、凭证号)。这张表是第 4–6 阶段的基础。
- **【建议】** 4,800 笔交易约等于每月 400 笔。用一个小脚本生成,再通过 ERPNext 的 Data Import 工具导入,不要一笔一笔手输。
- **【建议】** 每月在 ERPNext 结账(Period Closing Voucher),以便之后检查"结账后过账"。

**Mac 说明:** ERPNext 可以通过 Docker Desktop for Mac 本地运行,或者使用 Frappe Cloud 的试用站点。

**要做:** 每月约 400 笔交易,单据互相关联;建议用脚本生成后用 Data Import 导入;每月做期末结账。

## 第 5 阶段:月结与对账控制(简历第 2 条)

**【你的记录】** 在 Excel 和 Power Query 中建立月结工作簿,用来核对余额、调查时间差、跟踪异常。用 40 个植入错误(重复、期间错误、分类错误、未匹配付款)混在正常交易里来测试这些控制。

### 控制规则(每个控制一个 SQL 视图;输出的行 = 异常)【建议】

| # | 控制 | 规则 | 能发现 |
|---|---|---|---|
| 1 | 试算平衡 | 每个期间借方合计 = 贷方合计 | 借贷不平的分录 |
| 2 | 应收 / 应付明细账与总账核对 | 每月未结发票合计 = 控制科目余额 | 漏记或多记 |
| 3 | 银行匹配 | 银行流水 ↔ 付款:金额相等,日期相差 ±3 天以内,有参考号时参考号一致 | 未匹配付款 |
| 4 | 重复 | 同一往来单位、同一金额、相隔几天、凭证号不同 | 重复发票 |
| 5 | 截止 / 期间 | 单据日期所在月份 ≠ 过账期间,或在期间结账日之后过账 | 期间错误 |
| 6 | 分类 | 科目 × 成本中心组合不在允许的对照表中(例如返利记进了营业费用,而不是收入抵减) | 分类错误 |
| 7 | 未核销付款 | 付款没有核销到任何发票 | 未匹配付款 |

```sql
-- 示例:控制 4,可能重复的发票
SELECT a.voucher_no, b.voucher_no AS possible_duplicate, a.party, a.amount
FROM invoices a
JOIN invoices b
  ON a.party = b.party
 AND a.amount = b.amount
 AND a.voucher_no < b.voucher_no
 AND ABS(DATEDIFF(a.posting_date, b.posting_date)) <= 5;
```

### Excel Power Query 月结工作簿【建议步骤】

1. 连接到 SQL 视图(每个控制一个查询),以及按期间和科目汇总的总账余额。
2. 把每个明细账合计和对应的总账控制科目合并,加一列 *差额(Difference)*。
3. 加一列 *状态(Status)*:差额为 0 时为 OK,否则为 *需调查(Investigate)*。
4. 把所有控制的输出追加到一张 **异常登记表**(期间、控制、单据、金额、负责人、处理结果)。
5. 每个月只需 **全部刷新(Refresh All)**,然后逐条处理登记表。

**Mac 说明:** Mac 版 Excel 有 Power Query,但数据连接器比 Windows 版少,可能无法直接连数据库。到这一阶段再决定:在 Mac 上装 Windows(如 Parallels Desktop),或者改用其他工具,并在简历上写实际用的工具。

### 测试控制

1. **【你的记录】** 在干净的参考账本上运行所有控制:12 个月全部对平,期末余额没有无法解释的差额。
2. **【建议】** 在一个单独的开发副本上(带它自己的植入错误)编写规则。
3. **【你的记录】** 制作 **留出的测试账本**:一个副本,把 40 个四类植入错误混在正常交易里。**【建议】** 每类 10 个,并附一个 **答案表(answer key)** 文件,列出每一行植入的错误。
4. 在测试账本上运行一次控制,**不修改任何规则**,然后把被标记的行和答案表对比。

| 指标 | 公式 | 你的结果 |
|---|---|---|
| 召回率(Recall) | 找到的植入错误 ÷ 40 | **【你的记录】** 36 ÷ 40 = 90% |
| 误报(False positives) | 被标记但不在答案表中的行 | **【你的记录】** 2 |
| 精确率(Precision) | 36 ÷ (36 + 2) | 94.7%(由你的数字计算) |

**要做:** 写下漏掉的 4 个错误是哪些、为什么漏掉,以及 2 个误报是什么。**【建议】** 典型的漏报是金额略有不同的重复发票,精确匹配金额的规则发现不了。

## 第 6 阶段:预算差异与毛到净报告(简历第 3 条)

**【你的记录】** 按月、产品和成本中心比较实际与预算;拆分量差和价差;把毛到净扣减项与账面核对;在 Power BI 中做利润表与预算差异、毛到净收入桥接图、月结异常三个页面;写一份解释主要差异的管理报告。

### 公式

| 指标 | 公式 |
|---|---|
| 差异 | 实际 − 预算(÷ 预算得到 %) |
| 量差(Volume effect) | (实际数量 − 预算数量)× 预算单价 |
| 价差(Price effect) | (实际单价 − 预算单价)× 实际数量 |
| 净收入 | 销售总额 − 返利 − 价格补差 − 退货 − 现金折扣 |
| 毛到净核对【建议】 | 已计提金额 = 已支付结算 + 应计余额的变动 |

检查:每个产品的量差 + 价差 = 收入差异。

### Power BI【建议模型】

- 星型模型:总账和预算事实表,连接科目、成本中心、产品和期间维度表。
- 第 1 页 **利润表与预算差异:** 按月、产品和成本中心比较实际与预算,并拆分价差和量差。
- 第 2 页 **毛到净桥接图:** 瀑布图,从销售总额经过每一项扣减到净收入。
- 第 3 页 **月结异常:** 异常登记表中的未结项目,按控制、期间和账龄展示。

```
Actual   = SUM ( gl[amount] )
Budget   = CALCULATE ( SUM ( budget[amount] ), budget[version] = "v1" )
Variance = [Actual] - [Budget]
Var %    = DIVIDE ( [Variance], [Budget] )
```

**Mac 说明:** Power BI Desktop 只有 Windows 版。

### 测量节省的时间

- **【你的记录】** 同一套报告、同一数据集:手工 90 分钟,自动化 20 分钟(四舍五入减少 78%)。
- **【建议】** 手工流程 = 导出报表、用 VLOOKUP 填模板、重建数据透视表和图表、写差异表。自动化流程 = 全部刷新、刷新 Power BI、检查异常、写说明。两种方式都用秒表计时,计时记录保存在仓库里(`report/timing_log.csv`)。

**要做:** 按月 / 产品 / 成本中心比较预算与实际,拆分量价影响,把毛到净扣减项与账面核对;做 3 页 Power BI;用计时记录证明 90 → 20 分钟。
